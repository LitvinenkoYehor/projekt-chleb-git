# ProjektChleb

Projekt symulacyjny: wypiek chleba na zakwasie – od receptury, przez partie testowe, po degustację.

## Zespół i role
- Yehor Litvinenko – lider projektu, technolog (receptury), dokumentalista, tester/QA


## Struktura repozytorium
- `receptury/` – receptury
- `dokumentacja/` – harmonogram i lista zakupów
- `testy/` – karta oceny i wyniki partii testowych

## Organizacja pracy
Każda rola pracuje na osobnej gałęzi (`feature/...`), a zmiany trafiają do `main` przez pull requesty.
